# Bugbash — 2026-09-29

Reviewed queue dispatch, persistence and merge APIs, terminal parsing, panel
limits, command editing, startup cleanup, and shell integration. The existing
suite passed before this work. New regressions cover the following fixes.

| Failure | Result after the fix | Regression coverage |
| --- | --- | --- |
| A multiline queue item emitted a completion per line, allowing conditional commands to run after an intermediate success despite a final failure. | Blocks execute as one evaluation in the current shell; chaining uses the block's final status. | `multiline_queue_item_uses_its_final_status_for_chaining` across Bash, Zsh and Fish |
| Literal tabs and other ASCII controls in queued text became shell editor keystrokes. | Control bytes are shell-quoted before transmission. NUL commands are retained paused with an error, without sending partial input. | `queued_blocks_preserve_literals_and_shell_state`, `invalid_command_is_kept_paused_without_partial_input` |
| Submitting or saving trimmed significant whitespace, including escaped trailing spaces. | Nonblank commands retain their exact editor contents. | `submit_preserves_significant_trailing_whitespace` |
| Fish collapsed backslashes in quoted integration paths. | Path quoting preserves both backslashes and apostrophes across supported shells. | `integration_paths_preserve_quotes_and_backslashes_in_all_shells` |
| Failed disk rollback could lose a claimed command from memory and leave the queue unpaused. | The command remains in memory, paused, for persistence retries and review. | `failed_claim_rollback_retains_command_in_memory_paused` |
| Rollback discarded a command when an external item reused its ID. | Both commands survive with distinct IDs. | `rollback_preserves_an_external_item_with_the_same_id` |
| Claim I/O failures left an active queue, and manual resume could hide errors behind “queue resumed.” | Failures pause the queue and preserve the dispatch error. | `claim_io_failure_pauses_without_writing_to_the_shell`, `resume_keeps_dispatch_failure_visible_and_paused` |
| Duplicate persisted IDs made edits, merges and claims ambiguous. | Invalid snapshots are rejected and backed up through the existing corrupt-file path. | `duplicate_persisted_ids_are_preserved_as_corrupt_input` |
| Exhausted persisted ID counters could panic, reuse IDs or hang merging. | Allocation wraps past occupied IDs without overflow or an infinite loop. | `exhausted_ids_still_allocate_unique_items`, `merge_id_allocator_wraps_past_occupied_maximum` |
| Concurrent startup cleanup could delete a session directory before its lease existed. | Empty directories receive a startup grace period. | `sweep_preserves_a_session_before_its_lease_is_written` |
| Queue snapshots inherited potentially world-readable permissions. | On Unix, atomic snapshot files are created with owner-only permissions and exclusive creation. | `queue_snapshots_are_only_readable_by_the_owner` |
| Oversized OSC messages produced truncated working directories or lifecycle markers. | Oversized messages are ignored; subsequent valid markers still parse. | `oversized_markers_are_ignored_instead_of_truncated` |
| Oversized CSI parameters could manufacture recognized modes from truncated numbers and retain unbounded pending output. | Overflow discards mode interpretation and releases pending bytes. | `oversized_modes_are_streamed_without_truncated_mode_events` |
| Startup cursor queries removed CPR-shaped bytes from pasted text. | Cursor reports are extracted only outside paste and string-reply payloads. | `cursor_query_does_not_consume_pasted_cursor_reports` |
| Large queues wrapped panel row counts; tabs at maximum terminal width overflowed cursor arithmetic. | Width and height calculations clamp without wrapping or panicking. | `large_queues_do_not_wrap_or_overflow_panel_height`, `tab_near_maximum_terminal_width_does_not_overflow` |

The fixes retain the existing public function signatures and JSON shape. The
intentional validation change is rejection of duplicate queue IDs. Multiline
and control-containing commands now use the shell's builtin `eval`; assignments
still affect the hosted shell, and its command history can show the encoded form.

Validation uses the actual binary inside PTYs on macOS ARM64 with Bash 3.2.57,
Zsh 5.9 and Fish 4.9.3. `CMDQ_REQUIRE_SHELL_MATRIX=1` makes missing shells a
failure. The suite includes real Vim, less and Git, terminal resize and signal
cleanup, queue recovery, direct input, and independent sessions. Clippy runs
with warnings denied, alongside formatting and whitespace checks.

This is not exhaustive coverage of every terminal emulator or shell
configuration, and Linux was not executed locally. A PTY write failure can
occur after some input reaches the shell: retained commands are paused, but
recovery cannot prove whether side effects already happened. Review the shell
before retrying after such an error.
